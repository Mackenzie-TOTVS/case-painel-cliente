# Histórico de interações com IA

Esta pasta contém o histórico das interações com IA utilizadas durante o desenvolvimento do case técnico "Painel do Cliente".

## Ferramenta utilizada

A principal ferramenta utilizada durante o desenvolvimento foi o ChatGPT.

Utilizei a IA principalmente como apoio para:

- compreender os requisitos do case;
- decompor o problema em etapas;
- discutir decisões de implementação;
- gerar propostas iniciais de código;
- entender o funcionamento do código produzido;
- solucionar problemas de Git e GitHub;
- estruturar os testes;
- estruturar a documentação do projeto.

## Forma de trabalho

O desenvolvimento foi realizado de maneira incremental.

A cada etapa, procurei:

1. entender o objetivo da alteração;
2. aplicar a implementação;
3. executar a aplicação ou os testes;
4. verificar o resultado;
5. registrar a evolução através de commits;
6. seguir para a próxima etapa somente após validar a anterior.

O histórico contém momentos em que solicitei explicações mais detalhadas e mudanças na forma de orientação da IA.

Essas interações foram preservadas porque fazem parte do processo real utilizado durante o desenvolvimento.
