# 03 - Operação

## Objetivo deste documento

Este documento descreve como executar e testar o protótipo do Painel do Cliente em ambiente local e apresenta os principais pontos que ainda precisariam ser tratados antes de uma utilização em produção.

---

## Pré-requisitos

Para executar completamente o projeto, é necessário possuir:

- um navegador moderno, como Chrome, Safari, Edge ou Firefox;
- Python 3 para servir os arquivos localmente;
- Node.js e npm para executar os testes automatizados.

O projeto não utiliza banco de dados e não possui dependências externas de frontend.
